# DisplayMod — display settings for BLACK SOULS II

Replaces the game's built-in 640x480 fullscreen with proper display settings:

- **Mode:** windowed, borderless, fullscreen
- **Resolution:** window size or monitor resolution
- **Scaling:** stretch to fill the screen, keep aspect ratio (black bars) or x1/x2/x3 (sharp pixels)

Press **F5** in game to open the settings menu, or use "Display" on the title screen. **Alt+Enter** toggles windowed / fullscreen.

Works with the official 18+ patch and fan translations. Does not affect saves or achievements.

## Installation

1. Download **[DisplayMod-1.1.zip](https://github.com/N9verMore/DisplayMod/raw/main/DisplayMod-1.1.zip)**.
2. Extract it into the game folder so that the `DisplayMod` folder is next to `Game.exe`.
   To open the game folder in Steam: right-click the game → Manage → Browse local files.
3. Close the game and run `DisplayMod\install.bat`.

If you use a translation or patch, install the mod **after** it. If you install a patch or translation later, just run `install.bat` again.

To uninstall, run `DisplayMod\uninstall.bat`.
